# Legacy files — not active analysis

These files are preserved for genealogy and discrepancy checking. They include mixed-frequency, scenario-based, superseded or explicitly unfinished material. Their presence in the repository does not validate them.

In particular, `car_reconstruction_working_NOT_FINAL.csv` must not be treated as final market evidence, and the fixed-take-rate ASEAN wedge file is a scenario output rather than observed platform revenue.
