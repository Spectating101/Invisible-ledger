# Sources

`core_public_documents/` contains selected load-bearing public filings, results releases and reports. It is not the complete 800+ MB local source archive.

`manifests/` preserves URLs, retrieval metadata, hashes, file indexes, procurement logs and source coverage. Large downloadable documents can be recovered using these records and the acquisition scripts.

Not committed to this public repository:

- private advisor/student correspondence;
- Claude/ChatGPT histories;
- proposal application and signature forms;
- credentials and internal connector metadata;
- licensed database exports that are not cleared for public redistribution;
- exact duplicate source files;
- hundreds of bulk images and OCR artifacts that can be regenerated from public documents.
