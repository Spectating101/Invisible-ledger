# Empirical review certification lane

This directory now includes a reproducible advisor-review layer in addition to the issuer movement and mechanism analyses.

The review package is generated by:

```bash
python3 scripts/analysis/build_empirical_review_package.py --output build/empirical_review_package
```

It produces:

- `sample_rule_sensitivity.csv` — alternative sample boundaries shown side-by-side without declaring one approved;
- `census_admission_issues.csv` — stale/inconsistent census admissions detected under current hard exclusions;
- `hard_exclusions.csv` — source/period exclusions that are enforced in analysis;
- `bps_certification_matrix.csv` — internal BPS consistency checks plus cross-wave items that remain conditional;
- `KONG_DATA_REVIEW.md` — compact empirical review package for advisor discussion;
- `KONG_DECISION_SHEET.md` — one-page sample-boundary decision sheet.

## Boundary

This work does **not** rewrite the thesis. It does not change `docs/CURRENT_STATUS.md`, the manuscript, source documents, or Box's ASEAN/global modules. Its purpose is to make the empirical decision state explicit before any manuscript reconstruction.

## Key principle

No final sample N is advertised until the advisor decides the geography/business-scope rule. Strict country-direct, Indonesia-aligned segment, broader direct-candidate, and conditional country-reconstruction evidence are kept distinct.
