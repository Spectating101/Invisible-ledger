## 4. How to rebuild (all verified on 25 Oct)

Run from `papers/thesis_2026-10/reading/` unless stated. Needs pandoc, python-docx, LibreOffice (`soffice`), Chromium (node), Times New Roman installed.

1. `bash build_yzu_docx.sh` then `soffice --headless --convert-to pdf thesis_YZU_layout_<date>.docx` (YZU Word and PDF; takes about 15 seconds).
2. `bash build_reading.sh` (reading PDF and editing Word), `bash build_compact.sh` (stops if a key sentence in `keypoints.txt` is missing from the text, then update the file), `bash build_condensed_docx.sh`.
3. From the repository root: `python3 papers/thesis_2026-10/reading/build_preview.py`, then
   `pandoc papers/thesis_2026-10/PREVIEW_BEFORE_AFTER.md --from markdown-tex_math_dollars+fenced_divs+raw_html+strikeout --to html5 --standalone --css papers/thesis_2026-10/reading/style.css --css papers/thesis_2026-10/reading/style_redline.css --embed-resources --resource-path=papers/thesis_2026-10 --metadata pagetitle="Before and after" -o papers/thesis_2026-10/reading/preview.tmp.html`
   and, in `reading/`, `node print_pdf.js preview.tmp.html PREVIEW_BEFORE_AFTER_<date>.pdf && rm preview.tmp.html`. The status lines of the preview's first table are written in `build_preview.py` (edit them there when an item changes). `bash papers/thesis_2026-10/reading/build_redline.sh [BASE]` builds the redline.
4. `bash build_tracked_changes.sh [BASE] [LABEL]` (new this session; builds BASE in a temporary worktree and compares; refuses to write an empty result).
5. Numbers: `bash research/option_space_2026-10-01/rebuild_all.sh` (about 3 minutes; 398 checks, last run 25 Oct; no number has changed since). The empirical package for her Dropbox is built by `build_empirical_package.py` (a copy from 25 Oct was in the session scratch, which does not survive).
